네이버 데스크톱 도구 라는 이름의 별도 제품은 검색되지 않았고, 사용자가 말씀하신 게 아마 PicPick (픽픽) — 한국에서 만든 올인원
  데스크톱 그래픽 도구일 가능성이 높습니다 (네이버 블로그 / 카페에서 자주 추천되는 한국 사용자 친화 도구). PicPick / Windows 캡처 도구   / 알캡처 / 칼무리를 종합해 SCDeskTools 가 가질 만한 추가 기능을 정리했습니다.
  캡처 계열 (현재 베이스로 쉽게 확장 가능)

  1. 전체 화면 캡처 — 가상 데스크톱 1번 BitBlt 후 바로 클립보드 + note. 베이스 오버레이 없이 즉시 동작. 난이도: 매우 쉬움.
  2. 현재 모니터(활성 모니터) 캡처 — 커서가 있는 모니터만. 쉬움.
  3. 마지막 캡처 영역 다시 캡처 (Repeat Last) — 직전 영역 좌표 저장 → 재실행 시 즉시 재캡처. PicPick / 알캡처 핵심 단축키. 매우 쉬움.
  4. 고정 크기 영역 캡처 — 미리 지정한 W×H (예: 1280×720 썸네일) 사각형을 마우스 위치로 이동만. 유튜브 썸네일 / 아이콘 제작 시 유용.
  쉬움.
  5. 자유 형태(Freehand) 캡처 — 마우스 궤적을 폐곡선으로 → 마스크. 기존 영역 캡처에서 polyline 추가. 중간.
  6. 스크롤 캡처 — 대상 창에 WM_MOUSEWHEEL 보내면서 매 프레임 BitBlt → 합치기. 웹페이지 / 긴 채팅 캡처. PicPick 의 킬러 기능. 어려움 —
   동기화 까다로움.
  7. 딜레이 캡처 (3/5/10 초) — 단축키 후 N초 뒤 캡처. 메뉴 펼친 상태 캡처에 필수.

  측정 / 가이드 계열 (베이스 활용)

  8. 크로스헤어(십자선) 가이드 — 마우스 추적 십자선. 픽셀 정렬용. PicPick 표준 기능. 매우 쉬움.
  9. 격자(Grid) 오버레이 — 사용자 지정 N×N 픽셀 격자. UI 디자인용. 쉬움.
  10. 수평선/수직선 가이드 — 자유롭게 배치하는 always-on-top 라인 (스마트가이드). 중간.

  색상 계열 (기존 컬러피커 확장)

  11. 색상 팔레트 / 히스토리 — 추출한 색상 저장 + 라벨링 + 내보내기 (CSS/Hex 리스트). 쉬움.
  12. 색상 비교 / 대비 검증 — 두 색상의 WCAG contrast 비율 계산. 접근성 검증. 쉬움.
  13. 그라디언트 추출 — 두 픽셀 간 그라디언트 정의 → CSS 코드 생성. 중간.

  노트 / 후처리 계열 (기존 floating note 확장)

  14. 노트 위 주석/낙서 — note dlg 위에 라인/사각형/텍스트/하이라이트 그리기 후 클립보드 재복사. 중간.
  15. 노트 파일 저장 — PNG/JPG/PDF 저장 (저장 다이얼로그 + 파일명 패턴 Capture_yyyyMMdd_HHmmss). 쉬움.
  16. OCR (캡처 영역 → 텍스트) — Windows.Media.Ocr (UWP) 또는 Tesseract. 스크린샷의 글자를 클립보드 텍스트로. 중간.
  17. 노트 잠금 / 핀 모드 — 항상 위 / 마우스 통과(click-through). 참조 이미지 띄워두고 작업. 쉬움.

  유틸리티 (별 기능군)

  18. 화면 녹화 — Windows Graphics Capture API (Win10+). 가장 요청 많은 기능이지만 어려움.
  19. 화이트보드 모드 — 화면 위에 자유롭게 그리는 layered transparent overlay. 발표용. 중간.
  20. 돋보기 고정 모드 — 현재 dropper 가 한 번 픽 후 닫히는데, 항상 위에 떠있는 픽셀 돋보기. 쉬움.
  21. 창 정보 표시 — 마우스 아래 창의 클래스명 / HWND / 위치 / 크기 / 프로세스 정보 패널. 디버깅 / 자동화 작업자용. 쉬움.
  22. DPI / 해상도 정보 표시 — 모니터별 DPI · 가상 데스크톱 좌표 · 활성 창 클라이언트/논클라이언트 영역. 매우 쉬움.
  23. 항상 위(Always-on-top) 토글 — 호버한 창을 topmost 로 핀. 다른 앱 보면서 비교 작업. 쉬움.
  24. 눈 보호 모드 (블루라이트 필터) — 화면 전체에 노란색 layered overlay. 쉬움.
